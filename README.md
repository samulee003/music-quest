# 音符小勇者 Music Quest

給小朋友的樂理冒險遊戲：由預備級聽覺遊戲開始，按 ABRSM／Trinity 樂理一級內容推進；另設練習室，用正式五線譜學鋼琴按鍵與小提琴指法。

直接打開：https://samulee003.github.io/music-quest/

- 進度儲存在瀏覽器（localStorage），可在「家長及老師」頁用進度碼搬到另一部裝置。
- 美術：ChatGPT 生成；配音：Gemini TTS；背景音樂：Flow Music。
- 樂器音色：FluidR3 GM（Frank Wen，CC BY 3.0），經 gleitz/midi-js-soundfonts。
- 字體：Chiron GoRound TC、Fredoka、Noto Music（SIL OFL）。
